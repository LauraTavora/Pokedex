<h1> Pokédex Mobile – Batalhas e Exploração Pokémon </h1>
<h2> Sobre o aplicativo </h2>

O Pokédex Mobile é um aplicativo que permite aos usuários explorar o universo Pokémon de forma interativa, oferecendo uma experiência completa de consulta, filtragem, visualização de detalhes e batalhas simuladas entre Pokémons.

O aplicativo consome dados diretamente da PokéAPI, apresentando informações como nome, tipos, status, sprites e permitindo que o usuário escolha um Pokémon para batalhar contra um oponente gerado automaticamente.

Além da exploração visual, o app conta com um modo de batalha animado, com contagem regressiva, efeitos visuais, barras de vida dinâmicas e resultado final da batalha.

<h2> Principais funcionalidades </h2>

<h3> Exploração e consulta </h3>

  - Listagem de Pokémons em formato de grid
  
  - Busca por nome em tempo real
  
  - Filtro por tipo (Planta, Fogo, Água, Elétrico, etc.)
  
  - Visualização detalhada de cada Pokémon
  
  - Navegação entre Pokémons dentro do modal de detalhes
 
<h3> Modo de batalha </h3>

  - Escolha de Pokémon para batalha

  - Geração automática de oponente

  - Contagem regressiva animada (3, 2, 1, LUTEM!)

  - Animação de aproximação dos Pokémons

  - GIF de batalha simulando o confronto

  - Barras de vida diminuindo em tempo real

  - Resultado final da batalha:

     - Vitória

     - Derrota

     - Empate (quando nenhum Pokémon causa dano suficiente)

<h3> Interface e experiência </h3>

  - Splash Screen animada com efeito de abertura da Pokébola

  - Design inspirado no universo Pokémon

  - Animações suaves e feedback visual

  - Interface responsiva e moderna

<h2> Linguagens e tecnologias utilizadas </h2>

Para o desenvolvimento deste projeto, foram utilizadas as seguintes tecnologias:

  - Java (Android)

  - XML (Layouts Android)

  - Retrofit (consumo de API)

  - Glide (carregamento de imagens e GIFs)

  - PokéAPI (fonte de dados)

  - RecyclerView & ConstraintLayout

  - Material Design Components

<h2> Como utilizar </h2>

  <strong>1.</strong> Instale o aplicativo no dispositivo Android

  <strong>2.</strong> Aguarde a Splash Screen animada

  <strong>3.</strong> Explore a lista de Pokémons

  <strong>4.</strong> Utilize a busca ou filtros por tipo

  <strong>5.</strong> Toque em um Pokémon para ver seus detalhes

  <strong>6.</strong> Acesse o modo de batalha

  <strong>7.</strong> Escolha seu Pokémon e acompanhe a luta até o resultado final
